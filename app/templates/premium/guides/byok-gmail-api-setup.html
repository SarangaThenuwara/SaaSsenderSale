Phase 1: Creating the Google Cloud Project

To begin using SaaS Sender, you must first create a dedicated project within the Google Cloud Console. This project acts as the secure bridge between our automation engine and your mailbox.

Step-by-Step Configuration

  • Navigate to IAM & Admin > Create a Project.
  • Name your project "Outreach-Infrastructure" to keep it distinct from personal data.
  • Go to APIs & Services > Library and search for the Gmail API. Click Enable.

Phase 2: Defining the OAuth Consent Screen

Since you are bringing your own keys, you are effectively the "Developer" and "User" of your own application. This is why you must configure the internal consent screen.

  1. Select External User Type (or Internal if you have a Google Workspace).
  2. Provide your primary support email and a developer contact address.
  3. Critical: Add the https://www.googleapis.com/auth/gmail.send scope. This is the only permission the platform needs to dispatch your outreach.

Phase 3: Generating the JSON Credentials

Once the consent screen is active, go to Credentials > Create Credentials > OAuth Client ID.

Select Desktop App as the application type. This is requested by our security architecture because it allows you to maintain full control over the refresh tokens without requiring a server-side redirect vulnerability.

Download the resulting JSON file and upload it to your SaaS Sender dashboard. We never store the plain-text version; it is instantly encrypted using your session-specific key.
